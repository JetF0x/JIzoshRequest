# Rumble Team Shop

A [Deck Shop](https://www.deckshop.pro/)–style toolkit for **One Piece Treasure Cruise – Pirate Rumble**. You can build a team, get it graded, find units that fix its weak spots, and copy example teams.

## Features

| Page | What it does |
| --- | --- |
| **Team Builder** (`#/builder`) | 5 main slots (slot 1 is the leader) and 5 support slots. It blocks the same character twice, shows avg SPD/DEF/special CT, total HP and the type/class/style mix, saves your last team, and has a **Copy link** button for sharing. |
| **Team Checker** (`#/checker`) | Paste a share link, a team code or unit IDs to get S–F grades for **Offense, Defense & Sustain, Control, Synergy and Versatility**, plus an overall grade, warnings, and one-click unit swap suggestions. The builder shows the same panel live. |
| **Units** (`#/units`) | Every unit with Rumble data (1,400+). Search, filter by type, class, Rumble style, effect keyword, target criteria and GP/LLB, and sort by SPD, DEF, ATK or special CT. Unit pages show the ability, special, GP burst, LLB kit, action pattern and resilience as readable text. |
| **Top Teams** (`#/meta`) | Attack and defense archetypes you can open in the builder or share. |

### How grading works

`src/lib/rating.ts` scores each team from its units' max-level Rumble effects:

- **Offense**: ATK-style units, damage specials, crew ATK/Crit/SPD buffs, average SPD.
- **Defense & Sustain**: DEF/RCV-style units, heals, DEF/HP/Guard buffs, Provoke/Counter/Revive, resilience, average DEF.
- **Control**: DBF-style units, enemy debuffs, and hinderances (Paralysis, Silence, …), weighted by chance and duration.
- **Synergy**: how much of the team the type-locked and class-locked buffs actually reach, character conditions met, and type/class cohesion.
- **Versatility**: attack/sustain/control/support roles covered, the spread of targeting styles, and special cooldowns.

Suggestions swap out the member who matters least to the weakest category and test units from the database, newest first. The grades are heuristics to guide team building. They don't simulate battles.

## Development

```bash
npm install
npm run dev          # http://localhost:5173/JIzoshRequest/
npm test             # vitest unit tests
npm run build        # typecheck + production build to dist/
```

### Refreshing unit data

Unit data comes from the community [OPTC Database](https://github.com/optc-db/optc-db.github.io) (`units.js`, `families.js`, `rumble.json`, and the thumbnail table in `utils.js`). It's committed as `src/data/units.json`, so builds work offline. To pull the latest units:

```bash
npm run import-data                      # downloads from GitHub
OPTCDB_DIR=./optc npm run import-data    # or reads local copies of the four files
npm run build-meta                       # optional: regenerate example Top Teams
```

### Adding Top Teams

Edit `src/data/metaTeams.json`:

```json
{ "name": "My defense", "mode": "defense", "description": "Why it works", "units": [4987, 4148, 4082, 4096, 4041] }
```

Unit IDs appear on each unit page. Entries with `"source": "example"` were generated by `scripts/build-meta-teams.ts`. Leave that field out for community picks.

## Deploying

`.github/workflows/deploy.yml` builds and publishes to GitHub Pages on every push to `main`. In the repo, go to **Settings → Pages** and set the source to **GitHub Actions**. If the repository is renamed, change `base` in `vite.config.ts` to match.
